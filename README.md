# Ordering Service
This is a food ordering service in which a user creates a profile, add furthermore is able to order food.

## Functionality 

The following **required** functionality is completed:

* [ ] User uses firebase to log in and out of the database.

* [ ] User can choose between all restaurants, or their favorite.

* [ ] Firebase logs their order
* [ ] They see an order summary.
* [ ] Recent orders and history are tracked.

The following **extensions** are implemented:

* Firebase
